## Основы ассемблера 

Я веду файл `ассемблер.txt`, и тут расписано его содержимое

### Структура файла:

```nasm
section .bss  ; неинициализированные переменные
section .data ; переменные, которым сращу задается значение
section .text ; текст программы
```

### Про `global`, `extern` и линковщик

`global` помечает метку как метку, которую **можно вызывать из другой части программы** (если как часть мы берем 1 объектный файл) или как **точка старта программы**
`extern` помечает, что в коде **используется глобальная метка из другой части программы**

### Регистры

| Название регистра | Значение | Для чего применяется |
| --- | --- | --- |
| RAX | Аккумулятор | Определение системной функции, получение результата |
| RBX | Базовый регистр | Свободный для использования регистр |
| RCX | Счетчик циклов | Обычно в циклах как счетчик |
| RDX | Данные | Используется как аргумент для системной функции |
| RDI | Destination Index | Используется как аргумент для системной функции |
| RSI | Source Index | Используется как аргумент для системной функции |
| R8, R9, ..., R15 | Дополнительные регистры | Свободные регистры (**только в x86_64**), R10, R9 и R8 используются как аргумент системной функции |
